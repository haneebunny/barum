# create 샘플 데이터 체험 입력 기록

`create.json`(유어베리 핑크 글로우 세럼) 픽스처를 만든 입력값이다. 다시 똑같이
구우려면(배포본에서 create 실행 후 결과를 굽는 흐름) 아래 값을 그대로 넣는다.

실시간 캐시는 요청 전체를 해시하므로, 한 글자라도 다르면 캐시가 미스되고 새로
생성된다. 데모 버튼 자체는 이 픽스처를 그대로 렌더하므로 입력 재현이 필요없다.

## 입력값

- 제품명: 유어베리 핑크 글로우 세럼
- 타겟팅(notes): "20,30대 피부가 건조한 여성들을 타겟으로 한다. 그리고 텍스쳐가 핑크라는 것을 소구점으로 삼는다."
- 제형: 액상 / 용량: 30ml
- 이미지 생성: 켬(requested=true)
- 제품사진: 6장 업로드(hero·원인·성분·텍스처·임상2 카드에 원본 배치)

### 전성분(함량)
정제수 76.5, 글리세린 6, 부틸렌글라이콜 5, 나이아신아마이드 3, 프로판다이올 3,
판테놀 2, 베타인 1.5, 히알루론산 1, 1,2-헥산다이올 0.8, 하이드록시아세토페논 0.4,
카보머 0.25, 알지닌 0.2, 알란토인 0.2, 에틸헥실글리세린 0.1, 다이소듐이디티에이 0.05

### 실증자료(clinical)
- 다크스팟 개선 87%, 8주, 유어랩 피부과학연구소, 20명 대상
- 피부결 개선 2.1배, 4주, 유어랩 피부과학연구소, 20명 대상

### 설문조사(survey)
- 발림성 만족 94%, 유어리서치, 2026년 3월, 150명 대상 온라인 자기기입식 설문

## 다시 굽는 법
배포본에서 위 입력으로 create 실행 → genResult JSON을 저장 →
`scripts/bake_from_live.py <BACKEND_URL>`로 이미지 내려받아 `create.json` 교체.
