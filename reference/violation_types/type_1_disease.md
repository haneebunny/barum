# 1호 — 질병 예방·치료 효능 표방 (질병표방)

- **법조문:** [법 제8조①제1호](../statute/law.md) → [별표1 제1호 가~라목](../statute/appendix_1_prohibited_ads.md)
- **위해등급:** **최고** (법 제26조: 10년/1억, 과징금 대상)
- **라벨값:** `1호_질병표방`

## 정의 (별표1 원문 요지)

질병의 예방·치료에 효능이 있는 것으로 **인식할 우려**가 있는 표시·광고. 진위는 따지지 않는다(§3-2).

- **가.** 질병 발생 **예방** 주장 — 예외 ① 특수의료용도식품(질병명+"영양조절"), ② **건기식이 기능성 인정받은 사항**(질병발생위험감소기능, 예: 칼슘·비타민D→골다공증 위험 감소)
- **나.** 질병 **치료 효과**
- **다.** 질병의 특징적 **징후·증상**에 예방·치료 효과
- **라.** **질병정보**(질병·증상 관련 제품명·학술자료·사진)로 질병과의 연관성 암시 — 가장 넓다

## 판정 규칙 `[해석 v1.2.4]`

> **핵심: 라목이 가장 넓다. 효과 동사도 질병명도 필요 없다. "증상 나열"만으로 성립.**
> "○○로 고생하시나요?", "이런 분께 권합니다 + 증상 나열"이 전형적 라목.

- 제품 유형과 **무관**하게 우선한다(일반식품·건기식 공통). 2호(의약품)만 1호보다 우선.
- **갈림길:** 그 증상이 **특정 질병의 진단 단서**로 쓰이는가. 잔뇨·야간뇨·세뇨(전립선비대증 IPSS 문항), 잇몸 붓고 아픔(치주질환)은 라목. "피곤함·입맛 없음"은 비특이 증상이라 질병정보 아님.
- 의학 지식으로 증상↔질병을 연결하지 말 것. `product_name`·`certified_function`·문맥이 겨냥 질병을 알려준다.

### 라목 disclaimer(면책 병기) 예외 — 건기식만

| 조건 | 라벨 |
|---|---|
| 건기식 + 병기 있음 + 단순 질병정보 서술 | **합법** (라목 예외) |
| 건기식 + 병기 없음 + 질병정보 | **1호 라목** |
| **일반식품** + 질병정보 | **1호 라목** (예외는 건기식만) |
| 병기가 있어도 **예방·치료 효과를 주장** | **1호 가·나·다목** (예외 적용 안 됨) |

> ⚠️ 예외 요건 2개 모두 필요: ① 기능성 표시와 **명확히 구분**, ② **"해당 질병정보는 제품과 직접적인 관련이 없습니다"** 병기. 수집된 "제품과 관련없는 건강정보입니다" 류는 조문 문구와 달라 일괄 합법 처리 금지 → 병기가 다르거나 구분 불명확하면 `애매`.

## 실제 수집·적발 문구 → 1호

| 문구 | 목 | 이유 |
|---|:--:|---|
| 소변줄기가 가늘고 힘이 없어지며 중간에 끊어지기도 한다 | 라 | 전립선비대증 진단 문항(IPSS) |
| 밤에 잠을 자다 일어나 소변을 보아야 한다 / 잔뇨감이 있으신 분 | 라 | 야간뇨·잔뇨 |
| 잇몸이 붓고 아프다 | 라 | 치주질환 증상 |
| 간 기능이 떨어지면 간염·간경화·지방간이 발생할 수 있습니다 | 라 | 질병명 직접 나열 |
| 까다로운 당뇨병성 신장질환(비투석) 식이 관리 | 라 | 질병명 직접 사용 |
| 관절염 통증 개선 / 암 예방 / 방광염 완치 | 나·다 | 질병명+효과 동사 (식약처 적발) |
| 이석 재건 효과 / 이명 회로 차단제 | 나·다 | 질병 치료 표방 (이석증 11개소 적발) |

## 1호가 아닌 것 — 반례

| 문구 | 라벨 | 이유 |
|---|---|---|
| 입맛이 없거나 소화가 안된다 / 자꾸 피곤하다 | 합법 | 비특이 증상 |
| 몸은 피곤한데 누우면 생각이 많아지는 분 | 3호(일반식품) | 질병 아닌 수면 기능성 |
| 지구력이 떨어져 빨리 지치는 분 | 합법 | "지구력 증진" 인정 문구 |

## 원재료 주어 + 질병 (복합)

"○○ 성분은 항염/항암/혈압강하 효과" → **1호** (원재료가 주어여도 질병 관련이면 등급 상승, `note: 1호+5호 복합`).
