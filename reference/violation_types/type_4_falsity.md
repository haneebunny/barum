# 4호 — 거짓·과장 (거짓과장)

- **법조문:** [법 제8조①제4호](../statute/law.md) → [별표1 제4호 가~마목](../statute/appendix_1_prohibited_ads.md)
- **위해등급:** **中** (법 제27조: 5년/5천만원)
- **라벨값:** `4호_거짓과장`

## 정의 (별표1 원문 요지)

거짓·과장된 표시·광고. **진위를 따지는 유일한 호**(§3-2).

- **가.** 허가·등록·신고 또는 **보고한 사항과 다르게** 표현 (식품위생법·건기식법·축산물위생관리법·수입식품법)
- **나.** 건강기능식품이 **식약처장이 인정하지 않은 기능성**을 나타내는 내용 ← **건기식 월권이 여기**
- **다.** [시행령 제2조](../statute/enforcement_decree.md) 각 호(명칭·원재료·성분·내용량·제조방법 등)를 **사실과 다른 내용**으로 표현
- **라.** 제2조 각 호를 표시·광고할 때 **신체의 일부·신체조직의 기능ㆍ작용ㆍ효과ㆍ효능**에 관하여 표현 ← 실무 대부분
- **마.** **정부·공인기관의 수상ㆍ인증ㆍ보증ㆍ선정ㆍ특허**와 관련하여 **사실과 다른 내용**으로 표현

## 판정 규칙 `[해석 v1.2.4]`

`note`에 하위 목을 적는다:
- **나목** — 건기식이 인정 안 받은 기능성 ("눈가 주름 개선"인데 인정은 피부 보습). 진위 확인 불필요.
- **라목** — 신체조직 기능·작용 ("붓기 제거", "피부 탄력", "흡수율 120배"). 진위 확인 불필요.
- **마목** — 수상·인증·보증·특허 ("특허받은 성분", "1위"). **진위 확인 필요.**

> 실제 적발 문구는 **대부분 라목**(신체작용). 신체 부위·조직의 작용을 말하는데 건기식 인정 기능성 목록에 없으면 4호 라목.

## 실제 수집·적발 문구 → 4호

| 문구 | 목 | 이유 |
|---|:--:|---|
| 7일 만에 7.5kg 감량 (판매자 주장) | 다 | 구체적 감량 수치, 사실과 다름 |
| 체내 흡수율 최소 120배 | 라 | 흡수라는 신체작용 + 근거 없는 배수 |
| 식사 전 한 정 = 조깅 1.5시간 | 다 | 근거 없는 등가 주장 |
| 장의 활력 회복·신진대사 촉진·굳은 대변 배출 | 라 | 신체조직 작용 |
| 塩分(나트륨)을 흡착! / 피부에 쏙쏙 흡수 | 라 | 체내 작용 주장 |
| 붓기 제거 / 다리 붓기 / 피부 탄력 / 긴장 완화 / 붓기차 | 라 | 식약처 적발 문구(236건 '붓기차'=라목) |
| 청신경 관리 (이석증 식품) | 라 | 신체조직 작용 |
| 특허받은 성분 (특허 없음) | 마 | 특허 관련 사실과 다름 |
| 국내 1위 / 최초 / 유일 (근거 없음) | 마 | 수상·선정 사실과 다름 |

## 경계 — 4호 vs 다른 호

| 상황 | 라벨 |
|---|---|
| 후기 형식의 감량 수치 "3개월 -10kg 성공!" | **[5호 다목](type_5_deception.md)** (체험기) |
| 판매자 주장의 감량 수치 "7일 3kg 감량" | **4호 다목** |
| 건기식 인정 문구를 그대로 사용(일반식품) | **[3호](type_3_hf_misperception.md)** |
| 정부기관 인증이 **사실** | **합법**([certified_phrases.md](certified_phrases.md)) |
| 정부기관 인증이 **사실과 다름** | **4호 마목** (5호 아님) |

> **갈림길:** 사실관계 자체가 틀렸으면 4호, 사실은 맞는데 오인하게 만드는 방식이면 [5호](type_5_deception.md).
