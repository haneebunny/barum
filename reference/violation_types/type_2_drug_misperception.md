# 2호 — 의약품 오인 (의약품오인)

- **법조문:** [법 제8조①제2호](../statute/law.md) → [별표1 제2호 가~라목](../statute/appendix_1_prohibited_ads.md) → [고시 제2조1호](../statute/notice_2025_79.md)(한약 처방명)
- **위해등급:** **최고** (법 제26조: 10년/1억, 과징금 대상). 가장 위험한데 가장 드문 유형.
- **라벨값:** `2호_의약품오인`

## 정의 (별표1 원문 요지)

식품등을 **의약품으로 인식할 우려**가 있는 표시·광고. 진위 불문.

- **가.** 의약품에만 쓰이는 **명칭(한약 처방명 포함)** 사용
- **나.** 의약품에 **포함**된다는 내용
- **다.** 의약품을 **대체**할 수 있다는 내용
- **라.** 의약품의 효능·질병치료 효과를 **증대**시킨다는 내용

## 판정 규칙 `[해석 v1.2.4]`

- **모든 호 중 가장 우선.** 의약품 명칭·대체·효능증대가 보이면 2호.
- 고시상 가목 예시는 **"한약 처방명"에 한정** — "환·약재·한약 제형" 같은 단순 서술은 2호가목 아님(R009).
- **주의:** 실제 적발 분포 3~4%로 최소인데 위해등급은 최상. 11번가 상품명 검색으론 거의 안 잡히고(플랫폼 차단), **상세페이지 이미지 OCR 텍스트**에서 찾아야 한다.

## 실제 수집·적발 문구 → 2호

| 문구 | 목 | 이유 |
|---|:--:|---|
| GLP-1을 지원하고 포도당 대사를 돕고 지방을 최적화 | 라 | GLP-1 = 위고비·삭센다 계열 **의약품 기전명** |
| 위고비, 삭센다, 마운자로, 제니칼 | 가 | 의약품명 도용 (다이어트 식품 26개소 적발) |
| 위고프로·콘타드·이소틴 / 콘서타·이소티논 | 가 | 의약품 유사명칭 (AI 가짜 전문가 16개소) |
| 다이어트약 / 살 빼는 약 / 지방분해약 / 간장약 / 관절약 | 가 | "약" 명칭 사용 |
| 방풍통성산, 태음조위탕 | 가 | 한약 처방명 (조문 명시) |
| 펜트라민 | 가 | 전문의약품 명칭 모방 |
| 약 대신 / 처방 없이 / 병원 안 가고 | 다 | 의약품 대체 암시 |
