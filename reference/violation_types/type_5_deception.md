# 5호 — 소비자 기만 (소비자기만)

- **법조문:** [법 제8조①제5호](../statute/law.md) → [별표1 제5호 가~카목](../statute/appendix_1_prohibited_ads.md) → [고시 제2조3호](../statute/notice_2025_79.md)(무첨가·천연·100%)
- **위해등급:** **中** (법 제27조: 5년/5천만원)
- **라벨값:** `5호_소비자기만`

## 정의 (별표1 원문 요지)

소비자를 기만하는 표시·광고. **오인·혼동하게 할 우려**가 요건이라 진위 불문(대법원 2014두37863).

- **가.** **공인되지 않은 제조방법** 연구·발견 인용 (예외: 연구자 성명·문헌명·발표 연월일 명시)
- **나.** **원재료·성분의 효능을 해당 식품의 효능으로** 오인·혼동 ← 원료 주어 문장
- **다.** **감사장·체험기** 이용 또는 "한방", "특수제법", "주문쇄도", "단체추천" 유사 표현으로 현혹
- **라.** **의사·치과의사·한의사·수의사·약사·한약사·대학교수 또는 그 밖의 사람**이 보증·추천·사용한다는 내용 (예외: 연구·개발 직접 참여 사실만)
- **마.** 외국어 남용으로 외국제품·기술제휴 혼동
- **바.** 조제유류 용기에 유아·여성 사진
- **사.** 조제유류가 모유와 같거나 더 좋다는 오인
- **아.** 식약처 **인정 사항의 일부를 삭제·변경**하여 오인 ← 건기식 인정 문구 변형
- **자.** **기능성이 인정되지 않는 사항**을 인정된 것처럼 표현
- **차.** **이온수·생명수·약수** 등 과학적 근거 없는 추상적 용어
- **카.** 금지 첨가물 무첨가 강조로 해당 제품만 그런 것처럼 오인

## 판정 규칙 `[해석 v1.2.4]`

### 원재료 주어 문장 (나목)
"○○ 성분은 …" 구조. 효능 성격에 따라 등급 상승:

| 원재료 효능 내용 | 라벨 |
|---|---|
| **질병** 관련 | **[1호](type_1_disease.md)** |
| 건기식 인정 기능성(제품은 일반식품) | **[3호](type_3_hf_misperception.md)** |
| 인정 목록에 없는 신체 작용 | **5호 나목** |
| 성분 함유 **사실**만 진술 | **합법** |

> **유권해석(law.go.kr cgmExpc 제350123):** 원재료 효능을 식품 효능으로 전가 = 5호(기만). 단 문헌 정확 인용 + 연구자·문헌·연월일 명시는 5호 가목 예외.

### 체험기 (다목)
- **진짜/가짜 불문 5호.** 조문이 "체험기 이용"을 금지(진위 요건 아님).
- **화자가 소비자면 5호, 판매자면 [4호](type_4_falsity.md).** (같은 감량 수치라도)
- "2,800,000 누적 리뷰수 돌파" = 체험기가 아니라 **"주문쇄도" 유사 표현(다목)**.
- 예외: 극히 제한적 무죄 판례(재구매율만 강조·효능 강조 없음·편집 비중 작음, §4-8-4).

### 전문가 보증 (라목) — 정부기관은 아님
- "약사가 추천하는", "○○○이 애용하는" = 5호 라목. "또는 그 밖의 사람"이 있어 열거는 예시(연예인·인플루언서 포함 가능 → A1 애매).
- **다만 식약처·정부기관은 "사람"이 아니다.** 건기식 인정 표시는 법정 의무표기라 광고 주장이 아니다 → **"식약처 인정"은 5호가 아님**(3차 정렬 최대 오답원, 7건).

### 인정 문구 변형 (아·자목)
인정 문구 "체지방 감소에 **도움을 줄 수 있음**" → 광고 "체지방 감소"(단정) = **5호 아목**.

### 무첨가·천연·100% (카목 + 고시로 확정) ✅
[고시 제2025-79호 제2조3호](../statute/notice_2025_79.md)로 확정: "무MSG·무방부제"(규정 외 명칭)·"무콜레스테롤"(원래 없는 성분)·"무설탕/무가당"·"천연/자연"·"100%"·"슈퍼푸드/GI/GL" 오용 = 5호.
