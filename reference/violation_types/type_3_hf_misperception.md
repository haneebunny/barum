# 3호 — 건강기능식품 오인 (건기식오인)

- **법조문:** [법 제8조①제3호](../statute/law.md) → [별표1 제3호 가~라목](../statute/appendix_1_prohibited_ads.md) → [고시 제2조2호](../statute/notice_2025_79.md)
- **위해등급:** **高** (법 제26조: 10년/1억, 과징금 대상)
- **라벨값:** `3호_건기식오인`

## 정의 (별표1 원문 요지)

**일반식품인데** 「건강기능식품에 관한 법률」 제3조제2호의 **기능성**이 있는 것으로 표현. 진위 불문. 다음은 제외:

- **가.** 건기식 기준·규격의 **영양성분 기능·함량** 표시
- **나.** 식약처장이 고시하는 내용(= **기능성표시식품**)
- **다.** **특수영양식품 및 특수의료용도식품**의 영양보급 표시
- **라.** 발육기·성장기·임신수유기·**갱년기** 등 **영양보급 목적** 개발 제품 표시

## 판정 규칙 `[해석 v1.2.4]` — 가장 중요한 규칙

> **같은 문장이라도 제품 유형에 따라 결론이 반대가 된다.** 반드시 `product_type`과 `certified_function`을 보라.
>
> | 문장 | 일반식품 | 건강기능식품 |
> |---|---|---|
> | "면역력 증진에 도움" | **3호 위반** | **합법** (인정 기능성) |
> | "체지방 감소에 도움" | **3호 위반** | **합법** |
> | "잠드는 시간 단축" | **3호 위반** | **합법** |

- **3호는 건강기능식품에 적용되지 않는다.** 건기식이 인정 범위를 넘으면 3호가 아니라 **[4호](type_4_falsity.md)**.
- 일반식품이 건기식 **인정 기능성 문구**를 그대로 쓰면 3호. 인정 목록에도 없는 신체작용이면 [4호 라목](type_4_falsity.md).

## 실제 수집·적발 문구 → 3호 (모두 일반식품)

| 문구 | 이유 |
|---|---|
| 잠드는 데 걸리는 시간 단축 / 낯선 잠자리로 쉽게 잠들지 못할 때 | "수면의 질 개선" 기능성 표방 |
| 차로 마시는 프리바이오틱스 / '효소'로 장과 함께 운동 | 장 건강 기능성 |
| 체중 감량하고 가벼움을 / 최고의 지방 연소 파트너 | 체지방 감소 기능성 |
| 영양제 / 면역력 강화 / 체지방 감소 | 식약처 적발 문구 |
| ○○영양제 (알부민 식품 9개소) | 일반식품을 영양제로 표방 |

## 3호가 아닌 것 — 함정

| 문구 | 라벨 | 이유 |
|---|---|---|
| **갱년기 여성의 영양보급을 목적으로 개발된 제품입니다** | **합법** | 별표1 3호 **라목이 명시 제외** |
| 당뇨환자용 균형영양식 | 합법 | 특수용도식품 → 다목 제외 |
| 가르시니아캄보지아추출물은 '체지방 감소에 도움' 기능을 식약처 인정받은 원료 | 합법 | 건기식이 인정 문구를 정확히 인용 → [certified_phrases.md](certified_phrases.md) |
| # 체지방 감소 # 간 건강 (건기식) | 합법 | `certified_function` 범위 안 |
