# 금지·주의 표현 목록 (판정 지식 ①)

> 무엇: 광고 문구가 이 목록에 걸리는지 대조하는 표. 판정 엔진의 핵심 입력.
> 근거: 법 제13조 + 시행규칙 별표5 + 표시·광고 지침 + 2025 금지표현. (원문은 각 statute 파일 / `cosmetic_sources.md`)
> 메타: 기준일 [ ] · 확인일 [ ]

## 채울 것
- [ ] 금지 표현을 "유형별"로 모아 한 표에
- [ ] 각 표현에: 위반유형 라벨 + 근거(조/별표/지침) + 예시
- [ ] 판정 가이드라인의 3축(성분·브랜드 표기 / 일반 수식어 / 니즈 서술문) 결정과 짝을 맞춘다

| 치료, 재생, 염증 완화, 항염 | 1호_의약품오인 | 법13①1 | 의약품 효능 암시 |
