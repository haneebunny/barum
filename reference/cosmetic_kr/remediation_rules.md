# 화장품 위반 광고 문구 대체 표현 조건표 (수정 권고안)

이 문서는 화장품 광고 심사 중 위반으로 판단된 문구에 대해 안전하게 사용할 수 있는 대체 표현(권고안) 가이드라인을 정의합니다.

## 위반유형별 대체 표현 가이드

### 1. 1호_의약품오인 (의학적 효능·질병 치료 표방)
- **개념**: 화장품을 의약품으로 잘못 인식할 우려가 있는 표현(질병 진단·치료, 재생, 살균 등)
- **가이드**: 의학적 단어를 제거하고, 화장품 고유의 기능인 "보습", "피부 장벽 강화", "자극 완화" 등으로 전환합니다.

| 탐지 키워드 | 대체 표현 추천 후보 | 법적 근거 및 권장 팁 |
|---|---|---|
| 아토피, 건선, 가려움 | - 극건성 피부용 보습<br>- 건조함으로 인한 가려움 완화 | 질병명 언급 불가. 보습을 통한 일시적 완화 맥락으로 전환 |
| 염증, 항염, 진통 | - 피부 진정<br>- 자극 완화 | 의학적 효능 표현 배제. '진정' 또는 '보습' 표현 권장 |
| 여드름, 트러블 | - 민감성 피부 케어<br>- 피부 청결 유지 | 여드름성 피부 적합 적용시험 실증자료가 구비된 경우에만 '여드름성 피부 적합' 사용 가능 |
| 치료, 의학, 치유 | - 피부 장벽 케어<br>- 피부 보호 | 질병 치료 오인 단어 배제 |
| 재생, 세포재생 | - 피부 장벽 강화<br>- 피부 생기 부여 | 세포/피부 재생 표현은 의약품 오인 소지가 큼 |
| 소독, 살균, 항균 | - 피부 세정<br>- 청결 관리 | 세정제류 이외에 항균/살균 주장 금지 |
| 상처, 화상 | - 자극받은 피부 보호<br>- 일시적 손상 케어 | 상처 치료 연상 표현 금지 |
| 탈모, 발모 | - 두피 영양 공급<br>- 모발 윤광/탄력 케어 | 기능성 심사/보고가 완료된 제품만 탈모 증상 완화 도움 표현 가능 |
| 다이어트, 지방분해 | - 피부 탄력 증진<br>- 바디 탄력 케어 | 신체 개선 및 체형 변화 주장 불가 |

---

### 2. 2호_기능성오인 (심사받지 않은 기능성 광고)
- **개념**: 미백, 주름개선, 자외선차단 등 기능성화장품 심사·보고를 받지 않은 일반 화장품에서 기능성 효능을 표방하는 표현
- **가이드**: "피부 톤 개선", "영양/보습 공급", "피부 보호" 등 일반 화장품의 효능으로 전환하며, 기능성 심사/보고가 완료된 경우에만 고시 문구를 사용할 것을 권고합니다.

| 탐지 키워드 | 대체 표현 추천 후보 | 법적 근거 및 권장 팁 |
|---|---|---|
| 미백, 화이트닝 | - 피부 톤 개선<br>- 맑고 투명한 피부 연출 | 심사 완료 시에만 '미백 기능성' 표기 가능. 일반 화장품은 피부 톤/투명도 연출 맥락으로 수정 |
| 주름, 안티링클 | - 피부 탄력 개선<br>- 영양 공급 | 심사 완료 시에만 '주름개선 기능성' 표기 가능. 일반 화장품은 피부 탄력/영양 보습 맥락으로 수정 |
| 자외선차단, 선케어 | - 자외선으로부터 피부 보호 | 심사 완료 및 SPF/PA 수치 실증이 있는 경우에만 차단 효과 주장 가능 |

---

### 5. 5호_거짓과장기만 (소비자 오인 및 시술 표현)
- **개념**: 병원/피부과/약국 전용 표방, 니들/MTS 등 침습적 시술 오인 표현, 절대적 우위 표현(최고, 100%) 등
- **가이드**: 시술적 표현을 제형 흡수성 설명으로 바꾸고, 절대적 표현은 우수한 만족도/보습감 등으로 순화합니다.

| 탐지 키워드 | 대체 표현 추천 후보 | 법적 근거 및 권장 팁 |
|---|---|---|
| 병원용, 피부과전용, 약국용 | - 홈케어 전용<br>- 에스테틱 스킨케어 | 특정 기관 추천/독점 표방 금지 |
| 바늘, 니들, 미세침, MTS | - 피부 흡수율을 높인 포뮬러<br>- 스피큘 성분 함유 케어 | 화장품의 침습적 시술 효과 오인 금지 |
| 완벽, 최고, 최상, 100% | - 우수한 효과<br>- 만족스러운 사용감 | 객관적 근거 없는 절대적 표현 금지 |
| 피부나이 감소, 어려지는 | - 탄력 케어<br>- 피부 건강 유지 | 노화 예방 범위 내에서만 허용. 시간/나이 수치 감소 표현 불가 |
| 부작용 없는, 안전한 | - 피부 저자극 테스트 완료 | 부작용이 전혀 없다는 단정적 표현 금지 |
| 엑소좀, 줄기세포 | - 줄기세포 배양액 함유<br>- 피부 장벽 강화 효과 | 세포 자체 함유 오인 금지. 배양액 등 명확한 원료 명칭 표기 필요 |
