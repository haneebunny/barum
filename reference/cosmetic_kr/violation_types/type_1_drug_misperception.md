# 위반유형 1호 — 의약품 오인 (법 제13조 제1항 제1호)

> 무엇: 질병·치료·의학적 효능을 암시해 의약품으로 오인시키는 광고.
> 판정 안정성 경고: 평가에서 이 유형이 제일 안 갈렸다(4인 만장일치 0건, 안정성 0.00). 정의·예시를 제일 촘촘히 채워야 함.

## 채울 것
- [ ] 조문 근거(법13①1) + 별표5 의약품 오인 항목
- [ ] 판정 기준(무엇을 1호로, 무엇을 아닌 것으로) ← 판정 가이드라인 확정 후 반영
- [ ] 경계 표현 예시 10건+ ('진정', '시술 후', '민감/예민', '재생', '염증', '치료' 등)
