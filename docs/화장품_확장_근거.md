# 화장품 확장 근거: 데이터 가용성 + 수요 방어 (2026-08-08)

> 배경: 컴플라이언스 규제검증 방향(B) 확정 후, 1차 확장 도메인으로 화장품/의약품 검토.
> 성격: 조사 기반 판정 + 근거. 확정 결정 아님. 관련: `멘토링_피드백_정리.md`, `기술선택_비용성능_분석.md`, `PROJECT.md` §1.
> 검증일: 2026-08-08. 실크롤 프로브 + 공개 통계 조사.

---

## 0. 결론 요약

- **데이터 가용성: 화장품 "쓸 만함"(확정), 의약품 "빈약"(보류).** 화장품은 광고물·레퍼런스·정답신호 3박자가 다 있고 실크롤로 확인됨. 의약품은 규제(전문약 광고금지 + 일반약 사전심의)로 데이터가 구조적으로 눌려 있음.
- **수요 방어: 데이터로 방어됨.** 류건희 멘토의 "커머스는 자체 모니터링하니 굳이 안 산다"는 반론은, 화장품으로 가면 성립하지 않는다. 광고 책임 주체가 플랫폼에서 광고주(화장품 브랜드)로 바뀌고, 화장품은 사전심의가 없어 업체가 스스로 검증해야 하기 때문이다.
- 단 이 데이터는 수요의 프록시 신호(문제 규모·법적 책임·고객 수)이지, 지불의사를 직접 증명한 건 아니다. 진짜 검증은 고객 인터뷰가 남는다(§3).

## 1. 데이터 가용성 판정

### 1-1. 우리 현황

현재 보유 데이터·레퍼런스는 100% 식품/건기식(다이어트 보조제)이다. reference 코퍼스도 전부 식품표시광고법(식약처). 화장품/의약품 광고물은 0.

### 1-2. 화장품: 3박자 + 실크롤 실증

2026-08-08 실크롤 프로브(11번가 "기능성화장품", 8개 상품)로 확인.

| 확인 항목 | 결과 |
|---|---|
| 크롤 가능성 | 8/8 상품 `view-desc` 정상, 상세 이미지 142장 수집. 기존 11번가 파이프라인 그대로 작동 |
| 유료 API 비용 | 0원. 11번가 Open API(무료) + view-desc HTTP만. Gemini/OCR 미호출 |
| 광고 문구 존재 | 미백·주름·수치과장·후기보증 문구 풍부 |
| 기존 체계 이식성 | 기능성 오인·거짓과장·소비자기만이 우리 위반유형 체계와 그대로 매핑. 이미지 유형(후기/성분/제품컷)도 식품과 동일 |

프로브에서 실제로 관측된 부당광고 소지 문구(예):
- 아이크림: "다른 피부보다 5배 얇고, 피지선이 없어 건조함에 무려 100배나 취약" (실증 근거 없는 수치 주장), "눈가 주름 예방"(기능성 표방)
- 미백크림: "REAL REVIEW / 실사용 리뷰어" 후기 광고 포맷 + "WHITENING" 미백 기능성 표방

레퍼런스 코퍼스도 이미 공개돼 있다: 화장품법 제13조(부당 표시·광고 금지), 식약처 화장품 표시·광고 관리 지침(공개 PDF), 표시·광고 실증제, 2025 개정 금지표현 목록(엑소좀·마이크로니들·"피부나이 n세 감소" 등). 우리 `reference/statute` + `reference/violation_types` 구조를 화장품 버전으로 재구축 가능.

**결정적 이점:** 화장품 부당광고의 최다 유형이 "의약품 오인"(12,617건 중 8,727건, 약 69%)이다. 우리가 이미 가진 식품 위반유형 `type_2_drug_misperception`과 개념이 같다. 화장품·식품 둘 다 식약처 관할이라 위반 축(의약품 오인 / 기능성 오인 / 거짓과장 / 소비자 기만)이 공통이다. 식품에서 화장품으로의 이식 비용이 낮다.

### 1-3. 의약품: 규제로 데이터가 눌림

- 전문의약품은 대중광고가 법으로 금지(약사법 제68조 계열). 전문약 광고 데이터는 존재하지 않는다.
- 일반의약품·의약외품만 광고 가능하나 사전심의(한국제약바이오협회)를 통과해야 한다. 심의 통과분이라 위반 사례가 적고 물량도 적다. 온라인 판매·광고 매체도 제한적.
- 의약외품(탈모샴푸·무좀크림 등)은 온라인 광고·적발이 되므로 화장품에 곁다리로 얹을 수는 있으나, 단독 도메인으론 약하다.

## 2. 수요 방어 (류건희 멘토 반론에 대한 데이터 답변)

### 2-1. 반론 재확인

류건희 멘토: "큰 커머스는 자체 모니터링한다. 작은 데는 셀러가 위험부담을 진다. 굳이 돈 주고 서비스 안 산다." 신재웅 멘토: "상품 올리는 걸로는 잠잠해지는 게 맞다." → 커머스 상품탐지 프레이밍의 수요가 약하다는 지적.

### 2-2. 화장품 컴플라이언스가 이 반론을 무력화하는 5가지 (데이터)

1. **광고 책임 주체가 이동한다 = 고객이 바뀐다.**
   - 커머스 상품탐지에선 고객이 플랫폼이었고, 플랫폼은 자체 필터링을 한다(수요 약함).
   - 화장품에선 광고 실증 책임이 법적으로 광고주(화장품 책임판매업자) 본인에게 있다. 식약처가 실증을 요구하면 15일 내 자료 제출 의무, 못 하면 광고중지명령. 즉 리스크를 지는 주체가 곧 우리 잠재고객이다. 플랫폼이 대신 안 걸러준다.

2. **화장품은 사전심의가 없다 = 스스로 검증해야 한다. (핵심)**
   - 화장품 광고심의는 대한화장품협회의 자율 자문이지 법적 사전심의가 아니다. 신청도 자율.
   - 반면 의약품은 협회 사전심의가 있어 심의기관이 걸러준다(도구 수요 약함).
   - 화장품은 사후단속(적발·행정처분)만 존재한다. 그래서 업체는 올리기 전에 스스로 판단해야 하고, 여기서 자가검증 도구 수요가 발생한다. 우리 제품의 정확한 자리다.

3. **문제가 크고 증가 중이다 = 시장이 살아있다.**
   - 화장품 부당광고 적발: 2021년 1,913건 → 2022년 2,453 → 2023년 3,090 → 2024년 2,680. 3년 만에 40.1% 증가.
   - 2025년도 9월까지 2,481건으로 작년 초과 전망. 누적(2021~2025.9) 12,617건.
   - 단속이 강해질수록 자가검증 수요가 커진다.

4. **행정처분 = 실재하는 pain (돈이 걸린다).**
   - 광고업무정지 2~6개월은 매출 직결 타격. 최근 5개사(2025.12~2026.1) 광고업무정지, 별건 11개사 처분.
   - 최근 3년 허위·과장으로 적발된 책임판매업체 35개사, 10곳 처분 진행 중.
   - 광고업무정지는 브랜드에 치명적이라 미리 막을 유인이 강하다 = 지불의사 근거.

5. **고객이 많다 = 준법 인력 없는 중소 브랜드 다수.**
   - 화장품 책임판매업체 27,932개(2024). 2019년 15,707개에서 약 2배.
   - 중소기업 매출 연평균 16.8% 성장(산업 평균 6.5% 상회). 신규·중소 브랜드 폭증.
   - 중소 브랜드·유튜버는 준법 인력이 없다(신재웅 멘토 지목 타겟). 도구로 대체할 수요.
   - 시장 규모 22조원(2024).

### 2-3. 비교: 수요 축

| 축 | 커머스 상품탐지(기존) | 화장품 컴플라이언스(전환) |
|---|---|---|
| 고객 | 커머스 플랫폼 | 화장품 브랜드/책임판매업자 |
| 리스크 주체 | 플랫폼이 자체 처리 | 광고주 본인(실증 책임, 행정처분) |
| 사전 안전망 | 플랫폼 자체 필터 | 없음(사전심의 부재) → 자가검증 필요 |
| pain 크기 | 낮음(플랫폼이 흡수) | 높음(광고업무정지 = 매출 타격) |
| 잠재고객 수 | 소수 플랫폼 | 중소 브랜드 27,932개, 증가세 |

## 3. 한계와 다음 검증

- 위 데이터는 수요의 프록시 신호다: 문제 규모, 법적 책임 구조, 고객 수, pain 존재. 이것으로 "멘토의 수요 반론이 화장품에선 성립하지 않는다"는 방어는 된다.
- 그러나 지불의사를 직접 증명한 건 아니다. 진짜 product-market fit은 고객 인터뷰/사전 계약(LOI)로 검증해야 한다. B2B면 MOU/협의가 필요하다(신재웅 멘토).
- 발표·기획서에서는 "수요 반론을 규제 구조 + 공개 통계로 방어했고, 실수요는 고객 discovery로 검증 예정"으로 정직하게 프레이밍하는 게 강하다.
