## git · 규칙 (오늘 사고 1건 있었음, 교훈 반영됨)
- 기준 브랜치 `main`. origin = `github.com/haneebunny/barum.git`. `gh` CLI 없음, push 후 뜨는 PR 링크를 하니가 웹에서 열어야 함.
- **여러 세션이 같은 메인 워크트리(`/Users/hani/Desktop/project/barum`)를 공유한다.** `git add .` 금지, 파일 지정만.
- **⚠ 메인 워크트리에서 절대 `git checkout <다른 브랜치>` 하지 말 것.** 오늘 실제 사고: 백엔드 세션이 메인 워크트리에서 직접 체크아웃하다 로컬 `main`이 origin보다 70커밋 뒤처진 낡은 지점으로 HEAD가 튀어서, 다른 세션들 파일이 전부 몇 달 전 상태로 잠깐 바뀜(유실은 없이 복구함). **브랜치 작업이 필요하면 항상 `git worktree add <임시경로> -b <브랜치> origin/main`으로 격리.** 이번 세션 전체가 이 방식으로만 브랜치를 다뤄서 안전했다.
- 키는 `backend/.env`(gitignore): `GOOGLE_API_KEY`·`OPENAI_API_KEY`·`SUPABASE_URL`·`SUPABASE_KEY` 전부 설정 완료.
