## 학습셋 확대 계획 (VLM 라벨, 대수 실행 · 권고)

현재 학습셋 = VLM 라벨 132상품 / **4,225문장**. 총량 빠듯 + **2호(의약품오인) 거의 0**이라 확대 필요.

- **1단계 (무료, 크롤 없음):** 이미 크롤된 11번가 상품 279개 중 **미라벨 ~147개**를 OCR + VLM 라벨 → 예상 **+약 4,000문장**(상품당 keep ~32). → **총 ~8,000문장.**
- **목표치 (권고):** Phase 1 학습셋 **~8,000~10,000문장**, 클래스별 바닥 **가능하면 ≥150~200**.
- **2단계 (2호·희소 클래스 보충, 키워드 확장 탐색):** 2호는 다이어트 전용으론 안 늘어남. 아래 방향으로 **소량 탐색 크롤 먼저 → 키워드별 수율 보고 → 하니가 범주 확정** 후 본크롤.

  | 크롤 방향 (하니 승인 키워드셋) | 겨냥 위반유형 |
  |---|---|
  | 다이어트/비만 (위고비·GLP-1·비만치료제) | 2호·3호·4호 |
  | 카나비노이드·헴프·CBD 표방 식품 | 2호 |
  | 키성장 영양제 (키크는약) | 2호·1호 |
  | 집중력·수험생 영양제 (공부잘하는약) | 2호 |
  | 탈모 (비오틴 등) | 1호 |
  | 혈당·당뇨 영양제 | 1호 |

  - ⚠️ **주의:** 11번가 검색은 "THC·키크는약" 같은 **위반 표현 그대로는 잘 안 걸림**(셀러가 그렇게 제목 안 씀, THC는 국내 불법). 대수가 위 의도를 **검색 가능한 카테고리 키워드로 번역**해 탐색. 그 수율이 곧 범주 결정 근거.
  - **연구목적 소량수집** 유지(crawl-delay ≥ 1s). 탐색 단계는 키워드당 소수만.
- **주의:** VLM은 과금 호출. 재시도 없이 실패분만 기록·재실행(CLAUDE.md §E). Gemini 무료 15 RPM 스로틀 유지.
- **오너십:** [하니 목표수량 승인] → [대수 OCR+VLM 라벨 실행] → [하니 분포·품질 검수].
