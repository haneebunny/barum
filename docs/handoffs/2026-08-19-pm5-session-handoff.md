## 0. 너의 역할

barum 프로젝트 **PM**. 팀원별 작업 배분·조율, 팀장(의사결정자)과 각 세션 사이 중개, 큰 판단이 필요한 지점을 걸러서 팀장에게 확인받는 역할.

- 착수 규칙: `CLAUDE.md`(코드보다 인터뷰 우선, **§G 공유 워크트리 규칙 필독**, em-dash 금지, 한국어 짧게).
- 전체 로드맵 `ROADMAP.md`, 확정 결정 `PROJECT.md`.
- **트리아지 원칙이 2026-08-19 바뀌었다.** "발표(8/27) 후로 미루자"는 더 이상 기본값이 아니다. 되돌리기 쉽고 검증 가능한 건(특히 `rule_sweep.py`처럼 무료·결정론적으로 검증되는 영역) PM 판단으로 즉시 처리한다. 팀장 확인이 꼭 필요한 건: 정답셋 라벨 수정, 레퍼런스팩 구조 변경(새 위반유형 갈래 신설 등), 규제 동향 판단, 비용이 드는 결정. 상세: `[[barum-triage-no-defer-policy]]`(memory).
- **커밋 메시지·PR·공식문서에서 "팀장" 실명(하니) 금지.** 대체어는 **"팀장"**으로 고정(예: "팀장 확인", "팀장 지시"). PM이 직접 판단한 건 "PM 확인"으로 구분해서 쓴다. 팀원 실명(정빈·대수)도 금지, 팀원A/팀원B만. 채팅에서는 실명 불러도 됨, git에 올라가는 것만 적용. 상세: `[[barum-no-hani-name-in-commits]]`, `[[barum-team-naming]]`.
- `gh` CLI 오늘 설치 완료(Homebrew, `local_0d7e5be8...` 이 컴퓨터 전역이라 모든 세션이 공유). **인증(`gh auth login`)은 아직 안 됨** — 팀장이 직접 브라우저 로그인 해야 함. 인증되면 앞으로 모든 세션이 "PR 링크만 드립니다" 안 하고 직접 PR 열 수 있음.

### 이미지 생성
- Cloudflare(무료) 시도 → text-to-image 전용이라 원본 편집 불가 확인 → **OpenAI `gpt-image-1-mini`로 전환**(팀장 확인, "시연용 최소 사용" 전제).
- 1차 생성에서 병 라벨에 깨진 글자가 박히는 문제 발견 → **제품 자체를 안 그리고 원료·질감·추상 배경만 생성**하는 프롬프트로 전환(회피책 아니라 원래 맞는 설계 — 실제 제품샷은 셀러가 올리는 실사진이어야 함). 재테스트로 해결 확인.
- `images.edit` 분기는 나중에 "업로드 제품샷 + AI 배경 합성" 경로로 남겨둠.
- main 머지 완료(`feature/be-image-generation`).

### 평가지표 분리 (중요, 발표 소재)
- 합산 탐지율(61.9% 등) 방식 폐기. **①위반탐지율(15건, 회귀 체크리스트로 관리, 퍼센트 아님) ②검토필요 해소율(정보부족형/위반의심형 분리)**로 전환. 상세: `[[barum-eval-metric-split]]`
- 이유: 합산 지표는 "근거를 잘 붙일수록 점수가 깎이는" 구조였음(전성분 반영해서 올바르게 합법 판정해도 미탐으로 집계됨).
- 비비가 검토필요 166건을 정보부족형(118)/위반의심형(48)으로 재분류.
- `ingredients_group_diff.py`로 "전성분 받은 이미지/안 받은 이미지" 그룹 분리 검증 → 대조군(안 받은 그룹)이 0.0%p 움직여서, 처치군의 변화가 노이즈가 아니라는 첫 증거 확보. 다만 **반복 실행으로 편차 분포 재는 건 아직 안 함**(축소 표본으로 먼저 하기로 함, 미착수).
