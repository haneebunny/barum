- **호칭은 "PM 루루"로 통일**(세대 번호 안 붙임, 2026-08-19 팀장 지시).

- **커밋·PR·공식문서에서 "팀장" 실명 금지.** 대체어 "팀장"으로 고정. 팀원 실명(정빈·대수)도 금지, 팀원A/팀원B만.
- **`gh` CLI 인증 완료(2026-08-19).** 이제 모든 세션이 PR 직접 열 수 있다. **앞으로 push만 하지 말고 항상 PR까지 열 것**([[barum-always-open-pr]]).

## 6. 오늘의 교훈

- **"레퍼런스 참고해서 만들어라"는 지시는 구조(레이아웃)와 색을 분리해서 들어야 한다.** 오늘 이 둘을 안 나누고 전달해서 색상 방향이 세 번 넘게 바뀌었다(민트세이지→모노크롬로즈→카테고리별교차→최종: 이미지가 색 결정). 다음엔 "이 예시에서 뭘 배워와야 하는가"를 먼저 명확히 쪼개서 전달할 것.
- **실제로 만들어서 직접 봐야 한다.** 코드 리뷰·API 응답 JSON만으로는 "손 이미지만 반복" 같은 문제가 안 보인다. 오늘 여러 번 실제 생성해서 브라우저로 직접 확인한 게 진짜 버그를 잡은 유일한 방법이었다.
- **팀원이 스스로 "이건 팀장 판단 밖"이라고 짚어주는 걸 존중할 것.** 도도가 콜라겐·정답셋 라벨 건을 스스로 판단 안 하고 올린 게 여러 번 있었는데, 항상 맞는 판단이었다.
- 트리아지 정책(발표 후로 미루지 않기)이 실제로 잘 작동했다 — 아침에 "발표 후로" 보류했던 prescreen 43% 건도 새 근거 나오자마자 바로 착수 승인 받아서 처리함.
