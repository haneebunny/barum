## 오늘 조건부 (하니 승인 시 병렬 착수, 백그라운드 가능)

### 2. VLM 학습셋 확대 1단계 (미라벨 상품 라벨링)
- **착수 조건:** 하니의 **학습셋 목표 수량 승인**.
- **왜:** 현재 학습셋 = VLM 라벨 132상품 / 4,225문장. 총량 빠듯 + 2호(의약품오인) 거의 0.
- **실행:** 이미 크롤된 11번가 상품(약 279개) 중 **아직 OCR/라벨 안 된 ~147개**를 처리.
  - `scripts/run_ocr.py` → `scripts/run_prescreen.py` 로 OCR + VLM 라벨(hint) 생성 → `data/prescreen.jsonl`에 누적.
  - 예상 산출: 상품당 keep ~32문장 → **+약 4,000문장 → 총 ~8,000문장.**
- **목표치(권고):** Phase 1 학습셋 **8,000~10,000문장**, 클래스별 바닥 가능하면 ≥150~200.
- **주의:** VLM은 과금 호출 → **재시도 금지**, 실패분만 기록 후 나중 재실행(CLAUDE.md §E). Gemini 무료 15 RPM 스로틀 유지.
- **완료:** `data/prescreen.jsonl` 갱신 + **클래스 분포 표**를 하니에게 보고(특히 2호 몇 건인지).

### 3. 키워드 확장 탐색 크롤
- **착수 조건:** 하니의 **키워드셋 승인**.
- **왜:** 2호는 다이어트 전용으론 안 늘어남. 아래 방향으로 소량 탐색 크롤 → 수율 보고 → 하니가 범주 확정.

  | 크롤 방향 (승인 키워드셋) | 겨냥 위반유형 |
  |---|---|
  | 다이어트/비만 (위고비·GLP-1·비만치료제) | 2호·3호·4호 |
  | 카나비노이드·헴프·CBD 표방 식품 | 2호 |
  | 키성장 영양제 (키크는약) | 2호·1호 |
  | 집중력·수험생 영양제 (공부잘하는약) | 2호 |
  | 탈모 (비오틴 등) | 1호 |
  | 혈당·당뇨 영양제 | 1호 |

- **실행:** `collect_11st_details.py` 로 키워드별 **소량** 탐색 크롤(중복 A/B 자동 스킵).
  - ⚠️ 11번가 검색은 "THC·키크는약" 같은 **위반 표현 그대로는 안 걸림**(셀러가 그렇게 제목 안 씀, THC는 국내 불법). 위 의도를 **검색 가능한 카테고리 키워드로 번역**해서 탐색.
  - **연구목적 소량수집** 유지(crawl-delay ≥ 1s). 탐색 단계는 키워드당 소수만.
- **완료:** **키워드별 수율(상품 수·상세 수) 표**를 하니에게 보고 → 하니가 본크롤 범주 확정.
