> 실제 판정은 이 카드로 합니다. 근거·조문·판례는 `라벨링_기준서.md`에 있습니다.
> **막히면 해당 카드 번호로 기준서를 검색하세요.**

| 문장이 이런 모양이면 | 카드 |

## 카드 0. 공통 순서 — 모든 문장에 먼저

```
① product_type 확인        일반식품 / 건강기능식품 / 불명
② certified_function 확인   이 제품이 인정받은 기능성은?
③ disclaimer 확인          "제품과 관련없는 건강정보" 병기 있음/없음
④ 문장 읽기               애매하면 context_before / after 참고
⑤ 아래 순서로 검토         2호 → 1호 → 3호 → 4호 → 5호
```

**복합이면 위해등급 높은 것 하나만 라벨, `note`에 "1호+5호 복합"처럼 기록.**

**진위를 따지는 건 4호뿐.** 나머지는 "인식할 우려"가 요건이라 **사실이어도 위반**입니다.

## 카드 1. 증상·대상자 — "~하신 분", "~로 고생하시나요"

**이럴 때:** "이런 분께 권합니다" 아래 증상이 나열될 때

```
① 그 증상이 특정 질병의 진단 단서인가?
   │  (잔뇨·야간뇨·세뇨 → 전립선비대증 / 잇몸 붓고 아픔 → 치주질환)
   ├ 예 → ② 로
   └ 아니오 → ③ 으로

② product_type과 disclaimer 확인
   ├ 건기식 + disclaimer 있음 → 합법  (라목 예외)
   ├ 건기식 + disclaimer 없음 → 1호
   └ 일반식품              → 1호  (예외는 건기식만)

③ 질병이 아니라 '기능성' 영역인가? (수면·체지방·배변·관절·혈당…)
   ├ 아니오 (비특이 증상)     → 합법
   ├ 예 + 일반식품            → 3호
   ├ 예 + 건기식 · 인정 범위 안 → 합법
   └ 예 + 건기식 · 인정 범위 밖 → 4호 (나목)
```

| 예시 | 라벨 |
|---|---|
| 소변줄기가 가늘고 힘이 없어지며 끊어진다 | 1호 *(disclaimer 없으면)* |
| 밤에 자다가 일어나 소변을 보아야 한다 | 1호 *(같음)* |
| 잇몸이 붓고 아프다 | 1호 |
| 몸은 피곤한데 누우면 생각이 많아지는 분 *(일반식품)* | 3호 |
| 복부지방으로 고민중이신 분 *(건기식, 인정: 체지방 감소)* | 합법 |
| 평소 식이섬유 섭취가 부족하신 분 *(건기식, 인정: 배변활동)* | 합법 |
| 지구력이 떨어져 빨리 지치고 힘드신 분 *(건기식, 인정: 지구력)* | 합법 |
| 입맛이 없거나 소화가 안된다 | 합법 |
| 이런 분들께 추천합니다! | 합법 |

**갈림길:** "은근히 암시했나"가 아니라 **그 증상이 무엇의 증상인가**.
**애매하면:** `note`에 `증상 경계` → 기준서 §6-3 A7

## 카드 2. 원재료가 주어 — "○○ 성분은 ~"

**이럴 때:** 주어가 제품이 아니라 성분·원료일 때

```
그 원재료 효능의 내용이 무엇인가?

├ 질병 관련 (항암·항염·혈압강하·혈당강하)  → 1호   note: 1호+5호 복합
├ 건기식 인정 기능성 표현 + 제품은 일반식품 → 3호   note: 3호+5호 복합
├ 인정 목록에 없는 신체 작용               → 5호 (나목)
└ 성분 함유·함량 사실만 진술               → 합법
```

| 예시 | 라벨 |
|---|---|
| 비타민C는 항암 효과를 가지고 있습니다 | **1호** |
| ○○ 성분은 항염 효과가 있습니다 | **1호** |
| 알로에 겔은 비타민C 생체이용률을 3.04배 증가시켰습니다 | 5호 |
| 멜라토닌은 하루 주기리듬을 안정시켜 | 5호 |
| 감마오리자놀은 뇌의 각성도를 낮추는 작용으로 | 5호 |
| 셀레늄의 항산화 작용은 … 수정확률을 높입니다 | 5호 |
| 우리 제품은 비타민C를 함유하고 있습니다 | 합법 |
| 옥타코사놀 100 % | 합법 |

**갈림길:** 효능이 **질병**이면 1호로 올라갑니다. 주어가 원재료라고 등급이 내려가지 않습니다.

**두 문장이 이어질 때:**
> "비타민C는 항염 효과가 있습니다" → **1호**
> "우리 제품은 비타민C를 함유합니다" → **합법** + note "앞 문장과 결합 시 오인"
> **라벨은 효능을 주장한 문장에 답니다.**

## 카드 3. 인증·특허 — "식약처 인정", "특허받은", "1위"

**이럴 때:** 인증·수상·특허·순위가 나올 때

```
누가 보증하는가?

├ 정부·공인기관 (식약처, GMP, HACCP…)
│   ├ 사실이면          → 합법
│   └ 사실과 다르면      → 4호 (마목)   ※ 5호 아님
│
├ 사람 (의사·약사·교수, 그 밖의 사람)  → 5호 (라목)
│   └ 예외: 그 사람이 제품 연구·개발에 직접 참여한 사실만 → 합법
│
└ 특허·수상·선정
    ├ 사실이면          → 합법
    └ 사실과 다르면      → 4호 (마목)
```

| 예시 | 라벨 |
|---|---|
| 식약처에서 기능을 인정받은 건강기능식품입니다 | 합법 |
| 8종 기능성인정 건강기능식품 | 합법 *(애매 A4)* |
| 3종 식약처 인정 기능성 원료 배합 | 합법 |
| GMP 인증시설에서 생산됩니다 | 합법 |
| **약사가 추천하는** | **5호** |
| **의사가 만든** | **5호** |
| 특허받은 성분 *(특허 없음)* | 4호 (마목) |
| 국내 1위 / 최초 / 유일 *(근거 없음)* | 4호 (마목) |

**갈림길:** **기관이면 4호, 사람이면 5호.** "식약처가 인정"과 "약사가 추천"은 완전히 다릅니다.

**진위를 확인하려 하지 마세요.** 표현만 보고 확정하고 `note`에 `인정 건수` 또는 `특허 주장`.

## 카드 4. 후기·체험기 — "먹었더니", "−10kg 성공"

**이럴 때:** 소비자 경험담 형식일 때

```
① 화자가 누구인가?
   ├ 소비자 ("먹었더니", "○○님이", "동생이") → ② 로
   └ 판매자 ("7일 만에 3kg 감량")            → 4호

② 후기에서 무엇을 강조하는가?
   ├ 효능 · 감량 수치 · 증상 개선  → 5호 (다목)
   └ 재구매율 · 만족도만 (효능 없음) → 합법 (애매 A8)

③ 후기 내용이 질병을 말하면 등급이 올라갑니다
   ├ "관절염이 나았어요"          → 1호   note: 1호+5호 복합
   ├ "혈당이 잡혔어요"            → 1호   note: 1호+5호 복합
   └ (일반식품) "면역력 좋아졌어요" → 3호   note: 3호+5호 복합
```

| 예시 | 라벨 |
|---|---|
| 3개월만에 −10kg 성공! *(후기)* | 5호 |
| 동생이 먹는데 요즘 키 많이 컸어요 | 5호 *(식약처 적발 문구)* |
| 성공 사례의 진정한 공유 | 5호 |
| 2,800,000 누적 리뷰수 돌파! | 5호 *("주문쇄도" 유사)* |
| 7일 만에 3kg 감량 *(판매자 주장)* | **4호** |
| 재구매율 92% | 합법 *(애매 A8)* |

**갈림길:** **화자가 소비자면 5호, 판매자면 4호.** 수치가 있어도 후기 형식이면 5호입니다.
**진짜 후기든 가짜 후기든 5호**입니다 — 조문이 "체험기를 이용"하는 것을 금지합니다.

## 카드 5. 수치·논문·임상 — "3.04배", "12주 시험"

**이럴 때:** 숫자나 시험 결과가 나올 때

```
① 그게 체험기인가 임상시험인가?
   ├ 개인의 주관적 경험 → 카드 4로
   └ 통제된 시험       → ② 로

② 그 시험의 대상이 무엇인가?
   ├ 원재료·성분의 시험을 제품 효능처럼 → 5호 (나목)
   ├ 이 제품의 인정 기능성 범위 내 결과  → 합법 (애매 A3)
   └ 시험 조건·문헌 표시만              → 합법
```

| 예시 | 라벨 |
|---|---|
| 알로에 겔은 생체이용률을 3.04배 증가 | 5호 |
| 인체적용시험 12주간 관절이 불편한 50명에게 MSM 섭취 | 5호 |
| 뇌 GABA 농도 2.06배 | 5호 |
| 체지방량 −2.3kg 감소 확인 *(건기식, 인정: 체지방 감소)* | 합법 *(애매 A3)* |
| 시험 대상 : 평균 BMI 22.7 남성 16명 | 합법 |
| 체내 흡수율 최소 120배 | 4호 (라목) |
| 키위의 약 673배 | 4호 *(애매 A6)* |

> ### 수치의 진위를 확인하려 하지 마세요
> "120배"가 진짜인지 몰라도 **흡수율이라는 신체 작용을 말했으므로 이미 4호**입니다.
> `confidence = 확실`, `note`에 `수치 주장`.
> **`애매`는 어느 호인지 갈릴 때 쓰는 것이지, 사실 확인이 안 될 때 쓰는 게 아닙니다.**

## 카드 6. 인정 범위 — 건강기능식품이 기능성을 말할 때

**이럴 때:** `product_type = 건강기능식품`이고 효과를 말할 때

```
certified_function 열과 대조

├ 인정 문구를 그대로 인용            → 합법
├ 인정 문구의 기전·설명              → 합법 (애매 A2)
├ 인정 문구의 일부를 삭제·변경해 강화 → 5호 (아목)
├ 인정 안 받은 기능성                → 4호 (나목)
└ 인정 안 된 것을 인정된 것처럼       → 5호 (자목)
```

| 예시 | 인정 문구 | 라벨 |
|---|---|---|
| 차전자피 식이섬유 : 혈중 콜레스테롤 개선·배변활동 원활에 도움을 줄 수 있음 | 동일 | 합법 |
| 체지방감소·혈중 콜레스테롤 개선에 도움 | 동일 | 합법 |
| **눈가 주름 육안 평가 개선** | 피부 **보습** | **4호 (나목)** |
| **바디 라인 재조정** | 체지방 감소 | **4호 (나목)** |
| 젤리같은 질감으로 변 부피 증가 | 배변활동 원활 | 합법 *(애매 A2)* |
| "체지방 감소" *(단정)* | "체지방 감소에 **도움을 줄 수 있음**" | 5호 (아목) |

**갈림길:** 3호는 **건기식이 아닌 것**에만 적용됩니다. **건기식의 월권은 4호 나목**입니다.
**애매하면:** `note`에 `기전 설명` → 기준서 §6-3 A2

## 카드 7. 법정 표기 — "의약품이 아닙니다", "상담하십시오"

**이럴 때:** 주의사항·면책 문구처럼 보일 때 → **거의 다 합법입니다**

| 예시 | 라벨 |
|---|---|
| 어린이, 임산부 및 수유부는 섭취를 피하십시오 | 합법 |
| 간질환이 있거나 의약품 복용 시 전문가와 상담하십시오 | 합법 |
| 질환 보유자는 섭취 전에 **의사, 약사** 등 전문가와 상담하십시오 | 합법 |
| 본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다 | 합법 |
| ※ 인체적용시험 결과가 모든 사람에게 동일하게 적용되는 것은 아님 | 합법 |
| 논문 내용 모두 원재료에 대한 설명에 한합니다 | 합법 |
| ※ 제품과 관련없는 건강정보입니다 | 합법 *(+ 1호 라목 예외 근거)* |
| 본 제품은 특수의료용도식품으로 사용 전 의사와 상담하십시오 | 합법 |

**갈림길:** "전문가와 **상담하라**"는 **경고**, "전문가가 **추천한다**"는 **보증**.
앞은 합법, 뒤는 5호 라목입니다.

**면책 문구는 방패가 아닙니다.** 면책 문구 **자체**는 합법이지만, 앞의 효능 서술을 면책해 주지 않습니다.
그 효능 문장에는 위반 라벨을 답니다.

## 카드 8. 조각 — 말이 잘렸거나 제품명뿐

**이럴 때:** 문장이 판정 불가능할 때

| 예시 | 라벨 | note |
|---|---|---|
| 못하고 체외로 배출됨 | 대상외 | 문장 조각 |
| 수많은 다이어트 관련 기능성 원료 중 | 대상외 | 문장 조각 |
| 진피 3요소와 함께, 콜라겐의 흡수를 | 대상외 | 문장 조각 |
| 뉴케어 당플랜 프로 | 대상외 | 제품명 |
| 옥타코사놀 100 % | 합법 | 성분 표시 |

**갈림길:** 뒷말이 잘려 **주장을 알 수 없으면** 대상외. 짧아도 주장이 완결되면 판정합니다.

## 카드 9. 질병명이 나옴 — 간염·당뇨·관절염·전립선비대증

**이럴 때:** 문장에 질병 이름이 직접 등장할 때

```
① 효과를 주장하는가? ("예방", "치료", "개선", "완치")
   └ 예 → 1호 (가·나·다목)   ※ disclaimer 있어도 1호
   └ 아니오 ↓

② 질병 설명·정보 제공인가?
   ├ 건기식 + disclaimer 있음 → 합법 (라목 예외)
   ├ 건기식 + disclaimer 없음 → 1호 (라목)
   └ 일반식품                → 1호 (라목)
```

| 예시 | 라벨 |
|---|---|
| 관절염 통증 개선 / 암 예방 / 변비 개선 | **1호** *(효과 주장 — 예외 없음)* |
| 간의 기능이 떨어지면 간염, 간경화, 지방간이 발생할 수 있습니다 | 1호 *(disclaimer 없으면)* |
| 간 섬유증의 대표적인 간경변이며 알코올, B형 간염… | 1호 *(disclaimer 없으면)* |
| 전립선이 커지면서 요도를 눌러 각종 증상이 발생 | 1호 *(disclaimer 없으면)* |
| 까다로운 당뇨병성 신장질환(비투석) 식이 관리 *(일반식품)* | 1호 |

**갈림길:** **효과를 주장하면 disclaimer가 있어도 1호.** 예외는 **라목(정보 제공)에만** 적용됩니다.

> 특수의료용도식품이 섭취대상자의 질병명과 "영양조절"을 표시하는 건 **1호 가목 예외**입니다.
> 당뇨환자용·신장질환자용 영양조제식품이면 `note`에 `특수의료용도식품` 적고 `애매`로 두세요.

## 어디에도 안 맞으면

- 광고 문구가 아니면 (배송·결제·회사 정보) → **대상외**
- 판단이 안 서면 → **`confidence = 애매`** + `note`에 무엇이 걸리는지
- **억지로 찍지 마세요.** 애매 표시된 건은 모여서 함께 결정하고, 그 결정이 기준서 다음 버전이 됩니다.
