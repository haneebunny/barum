# 평가셋 라벨링 → 채점 가이드

> 목적: 대수가 라벨링을 끝내면 **명령어 하나로 AI 채점**까지 바로 가도록 미리 준비해둔 안내.
> 관련 파일: 라벨링 시트 `backend/data/cosmetic_eval_labeling.xlsx` · 채점 스크립트 `backend/scripts/score_eval.py`
> 담당: 라벨링=대수, 채점 실행=하니(또는 대수)

---

## 지금 상태

- 실제 화장품 광고 문구 **43개**로 라벨링 시트가 준비됨. (우리가 크롤해둔 데이터에서 뽑음. 추가 크롤 필요 없음.)
- 채점 스크립트도 준비됨. **라벨만 채워지면 바로 돌아감.**

---

## 1단계. 대수: 라벨링 (오늘)

1. `backend/data/cosmetic_eval_labeling.xlsx` 를 연다.
2. **안내 시트 먼저 읽는다.** (라벨 6종 설명 + 예시)
3. **라벨링 시트**에서 문장을 하나씩 읽고, **D열(라벨)** 을 드롭다운에서 고른다. E열(근거)에 왜 그렇게 봤는지 짧게.
4. 문장만 봐서 애매하면 같은 상품 이미지를 `backend/11st_probe_cosmetic/details/(상품코드)/` 에서 열어 맥락 확인.
5. 정말 모르겠으면 **애매(판단보류)** 로 두고 넘어간다. 억지로 찍지 않는다.

**꼭 기억할 것: 미탐(위반을 합법으로 놓침)이 제일 나쁜 실수다. 애매하면 합법으로 몰지 말 것.**

라벨 6종: 합법 / 1호_의약품오인 / 2호_기능성오인 / 4호_거짓과장기만 / 대상외 / 애매(판단보류)

---

## 2단계. 라벨 끝나면: AI 채점 (반나절)

터미널에서 (backend 폴더에서 실행):

```bash
cd backend

# 먼저 배선만 점검(Gemini 호출 없음, 공짜)
./venv/bin/python scripts/score_eval.py --dry

# 실제 채점(Gemini 호출, 43문장 텍스트라 사실상 공짜)
./venv/bin/python scripts/score_eval.py
```

- 준비물: `backend/.env` 에 `GOOGLE_API_KEY`(Gemini **무료 키** 권장).
- 43문장은 이미 글자라서, **이미지 자르기·화면 만들기 다 안 돼도 이 채점은 지금 돌아간다.** 이게 "우리 방식이 되나 안 되나" 제일 빠른 확인이다.

---

## 3단계. 결과 해석

스크립트가 이렇게 뱉는다:

- **전체 일치율** : AI가 대수 정답이랑 몇 % 같았나.
- **미탐(1급 지표)** : 대수는 "위반"이라 했는데 AI가 "합법/대상외"로 놓친 것. **이게 제일 중요. 낮을수록 좋다.**
- **오탐** : 대수는 "합법"인데 AI가 "위반"이라 한 것.
- **미탐 목록 / 오탐 목록** : 어떤 문장을 틀렸는지 그대로 보여줌.
- 상세표는 `backend/data/eval_result.xlsx` 에 저장(문장별 사람 vs AI vs 근거).

발표에서 쓸 숫자 = 일치율 + 미탐 건수. (표본 43개라 "확정"이 아니라 "경향"으로 말한다.)

---

## 4단계. 그 다음: 프롬프트 개선 루프

점수가 마음에 안 들면:

1. `backend/scripts/score_eval.py` 안의 `JUDGE_PROMPT`(판정 지침)를 고친다. 특히 **미탐 목록**에서 놓친 유형의 설명을 더 또렷하게.
2. 다시 `./venv/bin/python scripts/score_eval.py` 로 돌린다.
3. 점수가 오르는지 본다. 이 반복이 우리 "재학습 = 프롬프트 고도화"의 실체다.

프롬프트 실험은 무료 웹(AI Studio, ChatGPT 무료)에서 먼저 해보고, 확정된 것만 스크립트에 넣으면 API를 덜 긁는다.

---

## 주의

- **큰 배치 재크롤 금지.** 데모·평가엔 지금 있는 데이터로 충분.
- **유료 크레딧 대신 무료 키.** 43문장 채점 한 번은 원래 몇 원 수준이지만, 무료 키면 0원.
- 판정 지침(`JUDGE_PROMPT`)은 라벨링 안내 시트와 **같은 기준**으로 맞춰져 있다. 한쪽을 바꾸면 다른 쪽도 맞춰야 공정한 채점이 된다.
