# 고도화 전/후 비교표 (2026-08-23 정리)

> 담당: 도도(3대). **새로 측정하지 않았다.** 흩어진 기존 측정 기록을 한 표로 모은 것이다(API 비용 0).
> 포포가 슬라이드로 옮길 수 있게 만들었다. **각 줄의 "쓸 수 있는 형태"를 그대로 쓸 것.**

## 먼저 — 이 표를 읽는 법

**오염(in-sample)이 막는 것은 절대 수치지 상대 비교가 아니다.** 같은 셋·같은 조건으로 A와 B를
비교하면 오염이 양쪽에 똑같이 걸린다. 그래서 `60% → 65%`는 쓸 수 있고 `65%`는 단독으로 못 쓴다.

⚠ **다만 여기에 조건이 하나 붙는다.** 두 팔 중 **한쪽만 그 셋으로 튜닝했다면 상대 비교도
편향된다.** 규칙집을 963셋에 맞춰 고쳤다면 "규칙 있음 vs 없음" 비교는 규칙 쪽에 유리하게 기운다.
**"상대 비교는 오염에 면역"이 아니다.** 아래 표에서 그 조건을 만족하는지 줄마다 밝혔다.

---

## A. 쓸 수 있는 것 — 같은 셋·같은 조건 비교

| # | 무엇을 비교했나 | 전 → 후 | 조건 | 측정일 |
|---|---|---|---|---|
| A1 | **base 제로샷 → 배포 RagJudge**(규칙집+grounding) | 일치 **60.0% → 65.0%**<br>미탐 **1건 → 0건**<br>하드오탐 **11건 → 6건** | 같은 라벨셋 40문장, 동일 조건 | **2026-08-12** |
| A2 | **1차 필터 정비 전 → 후**(성분·제품명·천연 축 추가) | 판정 대상 통과 **51~55 → 63~65 / 65**<br>비대상 차단 21~22 → 21~22 | **홀드아웃 119문장**, 각 3회, 통과 쪽 범위 비겹침 | 2026-08-20 |
| A3 | **평가 배치 구성**(42문장 한 묶음 → 상품 단위) | 일치 **31~32 → 33~35 / 42** | 같은 셋, 각 3회, 범위 비겹침 | 2026-08-20 |

### A1이 방어되는 이유 — **측정 시점이 오염보다 앞선다**

A1은 **8/12** 측정이고, 규칙집을 963셋에 맞춰 튜닝한 건 대부분 **8/19~8/20**이다. 즉 A1 시점의
규칙집은 아직 그 셋에 맞춰 깎이지 않았다. **"상대 비교라서 괜찮다"가 아니라 "튜닝 전이라서
괜찮다"가 정확한 방어 논리다.**

⚠ **A1에 남는 한계**: 이 측정은 **ver1 라벨셋** 기준이다. 나중에 ver1이 963셋과 겹치는 35문장 중
**14건(40%)에서 합법 여부부터 어긋난 것**이 확인됐다(로그 ⑥). 두 팔을 같은 라벨로 채점했으니
**비교의 방향은 살아 있지만, 5%p라는 폭은 단단하지 않다.** 발표에서 폭을 강조하지 말 것.

### A2·A3은 성격이 다르다

- **A2는 개선이다.** 홀드아웃 119문장은 프롬프트·필터 실험에 쓰인 적이 없다.
- **A3은 개선이 아니라 측정 교정이다.** 운영은 상품 하나씩 판정하는데 평가기만 42문장을 한
  배치에 섞고 있었다. **"운영에 없는 구성을 재고 있었다"**가 정확한 서술이다.

## B. 절대 수치로는 못 쓰는 것 (상대 비교로만)

| 수치 | 왜 단독으로 못 쓰나 |
|---|---|
| 일치율 65% (A1의 후) | 40문장 in-sample. "65% 정확도"로 쓰면 안 된다 |
| 규칙 단독 위반탐지 8/16 | 규칙집이 이 셋으로 만들어졌다 |
| 규칙 오탐 0건 | 오탐 내는 후보를 계속 기각해온 결과. **회귀 감시용** |
| 증발 7 → 2 | 그 문장을 보고 키워드를 넣었다 |
| 검토필요 포착 63 → 106, 하드오탐 30 → 0 | 측정 도구가 **마지막 회차 값만** 찍고 있었다(수정됨, 재측정 안 함) |

## E. 아직 수치가 없는 것 (있는 척하지 않는다)

| 항목 | 상태 |
|---|---|
| KCA 실증자료 체크리스트 grounding 효과 | **미측정.** A/B 두 번 시도해 둘 다 실패(조건 오염 1회, 시간 초과 1회) |
| 전성분 투입이 2호 판정에 주는 효과 | **미입증.** 범위 겹침. 전성분 표시에 함량 %가 없어 "기준함량 충족 → 합법" 경로를 못 탄다 |
| 대체표현 LLM 층의 품질 개선 | **수치 없음.** 품질 스크립트는 "규칙집에 다시 걸리는가"만 재는데, 문장이 자연스러운지는 못 잰다 |
| 판정 설명 LLM 전환의 효과 | **수치 없음.** 스모크 4건뿐 |
| 근거 검증 게이트·할루시네이션 | 백엔드6 진행 중. 나오면 이 표에 추가 |

## 발표용 한 줄 (그대로 써도 되는 문장)

> **하한선 대비**: base 제로샷 60% / 미탐 1건 → 배포 파이프라인 65% / 미탐 0건 (같은 40문장, 2026-08-12, 규칙 튜닝 이전)
>
> **1차 필터**: 판정 대상 문장을 통과시키는 비율 51~55 → 63~65 / 65 (튜닝에 안 쓴 홀드아웃 119문장, 각 3회, 범위 비겹침)
>
> **재현성**: 같은 문장을 세 번 넣었을 때 같은 판정이 나오는 비율 90.5%
>
> **그리고 우리가 못 재는 것**: 오염 안 된 평가셋을 만들려고 재료를 세어 봤더니 쓸 수 있는 건 109문장이었다. 그래서 정확도 절대 수치는 주장하지 않는다.
