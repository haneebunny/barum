# 시연용 골든 입력값 (2026-08-23)

> 담당: 백엔드6. 팀장 지시 "어떤 자료를 넣었을 때 상세페이지가 예쁘게 나오는지".
> 아래 값은 **실제로 돌려서 나온 결과**다. 그대로 입력하면 같은 조건이 재현된다.
> 다만 생성은 실행마다 흔들리므로(`barum-vlm-run-variance`) 문구는 매번 달라진다.

---

## A. create 모드 — 그대로 입력할 값

| 칸 | 값 | 왜 이 값인가 |
|---|---|---|
| 상품명 | `유어베리 글로우 세럼` | **"리제너레이션"·"리페어" 같은 단어를 피한다.** 제품명 자체가 위반으로 잡힌다(리제너레이션 → 재생 동의어). 실제로 그 이름으로 돌렸을 때 재검증에 위반 1건이 남았다 |
| 인증서 | `미백 기능성 인증` | 문자열에 `미백`·`주름개선`·`자외선차단` 중 하나가 **들어 있어야** 인정문구가 나온다. `기능성화장품 심사필`은 매칭 안 됨(실측) |
| 성분+함량 | `나이아신아마이드 3%` / `히알루론산 1%` / `판테놀 2%` | **함량이 기준을 충족해야 한다.** 나이아신아마이드 1%는 실패, 3%는 통과. 성분이 여러 개여야 본문이 풍부해진다 |
| 제형 | `세럼` | 스펙표 조건 |
| 용량 | `30ml` | 스펙표 조건 |
| 추가정보 | `20~30대 여성 데일리 케어. 아침저녁 사용. 산뜻한 사용감 강조.` | 타겟·사용 맥락을 주면 카피가 구체적으로 나온다 |
| 프리셋 | `clinical_neutral` | 톤 통일 |
| 제품사진 | **브랜드명·용량이 선명한 사진 1장** | 라벨 보존이 이 사진 품질에 달렸다 |
| 이미지 생성 | 켬 | `IMAGE_GENERATION_ENABLED=1` 필요 |
| 실증자료 | 아래 2건 | **1건 = 카드 1장**(2026-08-23 변경). 넣는 만큼 임상 카드가 늘어난다 |
| 설문조사 | 아래 1건 | 효능이 아닌 항목만(발림성·재구매의향 등). 피부 변화를 말하면 거부된다 |

### 실증자료 (create 모드, 카드 1장씩)
```
다크스팟 개선 / 87%  / 유어랩 피부과학연구소 / 8주 / 20명 대상
피부결 개선   / 2.1배 / 유어랩 피부과학연구소 / 4주 / 20명 대상
```

### 설문조사 (메타데이터 6개 전부 필수)
```
발림성 만족 / 94% / 표본 150명 / 유어리서치 / 2026년 3월 / 온라인 자기기입식 설문
```
**`claim`에 피부 변화를 쓰면 안 된다.** 설문은 관리지침 [별표2]가 인정하는 실증
수단이 아니라, 효능을 말하는 순간 거부된다(`is_efficacy_survey`).

> 숫자는 데모용이다. 유어베리는 가상 브랜드다.

### 실제 결과 (실증·설문 포함)
```
재검증 위반 0 · 검토필요 3
카드 10장

[hero_intro]           llm                 도입 카피
[value_prop]           approved_claim      "피부의 미백에 도움을 준다."  ← 검증된 법정 문구
[ingredient_highlight] llm                 성분 소개
[texture_visual]       llm                 제형·발림성
[clinical_intro]       clinical_evidence   다크스팟 개선 87% (8주)
[clinical_result]      clinical_evidence   피부결 개선 2.1배 (4주)
[how_to_use]           llm                 사용법
[full_ingredient_list] full_ingredient     표 3행 (전성분)
[product_spec]         product_spec        표 2행 (제형·용량)
[survey_result]        survey_evidence     발림성 만족 94%
```

**카드 수는 고정이 아니다.** 사업자가 넣은 자료(실증·설문·전성분·스펙)는 자리가
없어서 빠지지 않고, 자유생성 카피만 상한을 받는다(팀장 지시 2026-08-23:
"항상 6장일 필요 없어"). 절대 상한은 12장이다.

**이 한 화면에서 오늘 고친 게 전부 보인다**: 인정문구가 히어로에 실리고(#321),
스펙표가 카드로 나가고(#314), 헤드라인이 짧고 본문이 채워지고(#311), 성분이
카피에 실제로 들어가고(#311), 사진 라벨이 살아 있다(#312).

## B. improve 모드 — 그대로 입력할 원문

**시연 효과는 이쪽이 크다.** 위반투성이 원문이 눈앞에서 정리된다.

```
줄기세포 배양 기술로 완성한 안티에이징 세럼
세포재생의 시작, 피부 재생 솔루션
손상된 피부 세포를 빠르게 재생하여 되돌립니다
진피층까지 깊숙이 침투하여 콜라겐 밀도 38% 증가 (4주 사용시)
아토피 개선에도 도움을 줍니다
전국 약국 오프라인매장 입점!
```
상품명은 `유어베리 글로우 세럼`.

### 실제 결과 (96초)
```
남은 위반어: 없음   (줄기세포·세포재생·진피층·재생·아토피·깊숙이 전부 사라짐)
대체표현 5건 전부 적용, 미적용 0
재검증 위반 1 · 검토필요 1
```
```
'줄기세포 배양 기술로 완성한 안티에이징 세럼'  → '피부에 생기와 윤기를 더해주는 세럼'
'세포재생의 시작, 피부 재생 솔루션'          → '피부에 생기와 활력을 선사하는 솔루션'
'손상된 피부 세포를 빠르게 재생하여 되돌립니다' → '거칠어진 피부 결을 매끄럽게 가꿔줍니다'
'진피층까지 깊숙이 침투하여 콜라겐 밀도 38%…'  → '4주 사용 시 콜라겐 밀도 38% 증가 (인체적용시험 결과)'
'아토피 개선에도 도움을 줍니다'              → '극건성 피부에 적합한 보습 케어를 제공합니다'
```

**시연에서 짚을 두 가지**
1. **수치를 안 지운다.** `38% 증가`가 살아남고 실증 고지가 붙는다. 사업자가 실제로
   측정한 값일 수 있어 임의로 빼면 그의 근거를 우리가 없애는 셈이다.
2. **질병명은 안전 표현으로 바뀐다.** `아토피 개선` → `극건성 피부에 적합한 보습 케어`.

### 남는 1건은 설명하고 넘어가면 된다
`전국 약국 오프라인매장 입점!` — 유통 채널 안내라 **바꿀 효능 표현이 없다.**
억지로 문구를 만들면 근거 없는 주장을 새로 넣는 셈이라 설계상 제안하지 않는다.
"고칠 수 없는 것은 고치는 척하지 않는다"를 보여주는 자리로 쓸 수 있다.

## C. 피해야 할 입력 (실측으로 확인된 함정)

| 하지 말 것 | 왜 |
|---|---|
| 상품명에 `리제너레이션`·`리페어`·`재생` | 제품명 자체가 위반으로 잡혀 재검증에 남는다 |
| 인증서를 `기능성화장품 심사필`로 | 카테고리 이름이 없어 인정문구가 안 나온다 |
| 함량을 비우거나 기준 미달(나이아신아마이드 1%) | 인정문구가 안 나온다. create는 improve보다 엄격하다 |
| 제형·용량을 비움 | 스펙표 카드가 아예 안 생긴다 |
| 제품사진 없이 이미지 생성 | 라벨 없는 배경만 나온다(그게 맞는 동작이다) |

## D. 사전 확인 (시연 직전)

```bash
# 1. 서버가 최신인지
curl -s localhost:8000/openapi.json | python3 -c "import json,sys; print('table_rows' in json.load(sys.stdin)['components']['schemas']['ContentCard']['properties'])"

# 2. 이미지 생성이 켜져 있는지  → backend/.env 에 IMAGE_GENERATION_ENABLED=1
```
첫 명령이 `False`면 낡은 프로세스다. 오늘 이 때문에 한 번 헤맸다.

**캐시가 켜져 있어 같은 입력을 두 번째 넣으면 즉시 나온다.** 시연 전에 한 번
미리 돌려두면 대기시간이 사라진다(107초 → 4ms 수준). 설정을 바꾸면 캐시 키가
자동으로 갈리므로 따로 비울 필요 없다.

## 한계
- 생성은 실행마다 흔들린다. 위 문구는 **그 실행의 결과**이지 매번 같은 문장이 아니다.
- create 카드 구성(어떤 모듈이 뽑히는지)도 실행마다 다르다. 인정문구가 붙는 자리는
  위험 모듈이 있으면 그쪽, 없으면 히어로다(#321).
