# docs/result/

발표·데모나 나중 고도화에 쓸 결과물·보고서·분석 자료를 모아두는 곳이다(2026-08-12, 하니 지시).
작업 중 산출물(핸드오프·목업)이 아니라, **정리된 산출물**이 여기 온다.

- 코드가 참조하는 살아있는 레퍼런스 문서(`reference/`, `docs/라벨링_기준서.md`·`docs/판정카드.md` 등)는
  여기로 옮기지 않는다. `reference/`가 실제로 다시 참조하는 문서(예: `docs/화장품_확장_근거.md`)도
  경로가 깨지니 옮기지 않는다.
- 새 보고서·분석·평가 결과를 만들 때는 처음부터 여기에 쓴다.

- `과대광고_VLM판정_예비리포트.md` — VLM 판정 예비 리포트
- `기술선택_비용성능_분석.md` — DL vs LLM 등 기술선택 비용/성능 분석
- `멘토링_피드백_정리.md` — 멘토링 피드백 정리
- `평가셋_채점_가이드.md` — 평가셋 채점 방법론
