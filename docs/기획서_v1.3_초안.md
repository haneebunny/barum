# 기획서 v1.3 확정 스펙 (2026-08-09)

> 인터뷰로 확정한 요구사항 기록. 정식 산출물은 `2조_최종프로젝트_기획서_v1.3.docx`(리포 루트, 양식 반영).
> 이 문서는 그 확정 근거의 압축 기록이다. 상세 서술은 .docx 참조.

## A. 방향·타겟·엔진
- 컴플라이언스 규제검증, 도메인 = 화장품
- 타겟 = 화장품 브랜드(자가검증). 감독기관 콘솔은 폐기(향후 B2G)
- 엔진 = LLM-first 전체. DL은 시간 남으면 검증용 보조
- 순서 = 국내 검증(1단계) → 미국 프리플라이트(2단계, 4~5주차 조건부)

## B. 제품 = 3 phase, 화면 3개
- 출시 전 / 출시 후 / 수출. 세 phase는 "입력 × 국가"의 변형
- 화면 3개: 홈(검사 이력 + 3 phase 입구) / 새 검사(입력 + 국가 선택) / 리포트
- 로그인 없는 단일 작업공간. 이력 저장(재업로드 불필요). 계정·회원은 향후

## C. 입력 (phase별)
- 출시 전: 기능성 문구 + 원료(가능하면 함량까지) 텍스트
- 출시 후: 상세페이지 이미지 직접 업로드 (URL 크롤 아님)
- 수출: 위 입력 + 국가 = 미국
- 11번가 크롤은 사용자 입력이 아니라 평가셋·데모 데이터 구축용 내부 도구

## D. 판정 로직 = DB 3표 + 체크 3개
- DB/RAG 3표
  1. 금지·주의 표현 목록 (화장품법 제13조 + 시행규칙 별표5 + 식약처 지침 + 2025 금지표현)
  2. 기능성 고시원료표 (성분 ↔ 기능 ↔ 기준 함량: 미백/주름/자외선차단)
  3. 미국 팩 (클레임 분류 + FDA 리스트: 자외선차단 활성·미승인 필터, 사용금지·제한 성분)
- 체크 3개
  1. 문구가 금지·주의 표현에 걸리나
  2. 기능성 클레임인데 그 기능의 고시원료가 기준 함량으로 있나
  3. (미국) 문구·성분이 미국선 의약품이 되나 + 리스트에 걸리는 성분 콕 집기

## E. 성분 판정 경계
- 함: 성분이 클레임을 뒷받침하나 (고시원료 ↔ 클레임 ↔ 함량 매칭)
- 안 함: 전체 성분 안전성 DB (배합한도·유해성 전수) = ChemLinked 영역
- 함량: 데이터 있으면 기준 대조, 없으면(이미지 전성분 등) "함량 확인 필요 + 기준 안내"

## F. 미국 프리플라이트 (2단계)
- 클레임 분류(drug/cosmetic) + 명확한 FDA 리스트 기반 성분 콕 집기
- 데모 hero = 선크림 (SPF 클레임 + 미국 미승인 UV필터 → 판매 불가)
- 색소·기타 OTC 활성·비건/할랄/GMO = 향후

## G. 리포트
- 위반 유형 + 근거(조항·금지표현)까지만. 대체 표현 제안 없음(법적 리스크). 확정은 사람. 법적 자문 아님 고지

## H. 평가·데이터
- LLM 보조 라벨링(VLM 초안 → 사람 확인) + 합성 증강(희소 유형만)
- 성능표 = 진짜 광고 + 사람 라벨 소량(30~50문장), 핵심 유형 중심
- 식품 라벨셋은 방법론 검증 성능표로 재활용
- 철칙: 합성데이터로 성능표 내지 않음

## I. Out / 향후
- Out: 전체 성분 안전성 DB, 등록·인증 대행, 로그인·계정, 감독 콘솔, 챗봇, 실시간 모니터링, 대체표현 제안
- 향후: 미국 외 국가 팩, 표시·인증(비건 등) 축, 레퍼런스 열람 화면, B2G

## J. 페르소나·팀·일정
- 페르소나 3명: 정민석(중소 브랜드 마케팅·준법), 유진아(인디 브랜드 대표), 박기덕(수출 담당)
- 팀: 하니(총괄)·정빈(FE)·대수(BE), DL 미정
- 발표 8/27, 기간 ~8/30

## 검증 조항 메모 (실측 확정)
- 화장품법 제13조①: 1호 의약품 오인 / 2호 기능성 오인 / 3호 삭제 / 4호 그 밖의 거짓·기만. 세부 유형은 시행규칙 제22조 별표5
- 나이아신아마이드 = 미백 고시원료(2~5%). 주름 고시원료 = 아데노신(0.04%)·레티놀 등. "나이아신아마이드로 주름개선 표방"은 2호 소지
