## 3. 디자인 시스템 (규칙 = 반드시 지킬 것)

- **폰트:** Pretendard(CDN). 숫자 전부 `tabular-nums`.
- **레퍼런스 톤:** 정부24(KRDS)의 명료함 — 화이트·정부 블루·소프트 카드. 단 **친근함(마스코트·둥근 이모지)은 제거**, 기관형 콘솔 밀도.
- **토큰:** 모든 색이 CSS 변수(`:root`). **5개 파일 토큰 100% 동일**(검증됨). 새 값 추가 시 5파일 동기화.
  - 라이트: `--canvas:#f3f5f8 --surface:#fff --navy:#1f2d44 --accent:#12509e`
  - 시맨틱: `--crit:#c0392b --warn:#9a5b02 --ok:#1f7a44 --low:#5b6472`
  - 다크: `--accent:#5b9be8` / `[data-theme="dark"]` 재정의 + 상단바 토글(달/해), 최초엔 시스템 설정 따라감.

### 🔑 핵심 규칙 5가지 (AI-slop 방지)
1. **색은 '주목'에만.** 위해 고·기한 초과·미이행·미탐 등 "지금 급한 것"만 색. 나머지 상태·라벨은 회색 텍스트. **전부 칠하면 강조가 사라지고, 전부 안 칠하면 위계가 사라진다.**
2. **왼쪽 border 굵게 금지** (`border-left:3px`). 전형적 AI-tell. 강조는 사방 균일 테두리 + 헤더 태그로.
3. **손그림 SVG 아이콘 금지.** 라이브러리(Phosphor/Tabler 계열) 아이콘 사용. em-dash(—) 금지 → 하이픈.
4. **상태는 색이 아니라 모양·글자로.** 색각이상 대응. (§4 참조)
5. **점수 아니라 근거.** "위험 0.94" ✗ → "확인 필요 · 근거 3건" ○. AI는 위반을 **확정하지 않음**("확인 필요"·"의심").

### 확립된 컴포넌트
- **상태 뱃지**(`.state`/`.htag`): border+옅은배경+텍스트. 경보만 색(고=빨강), 나머지 회색. 큐와 대시보드가 **같은 컴포넌트** 사용.
- **증거 = 방패(shield) 계열 아이콘:** 완료=shield-check / 부분=shield-half(반쪽 채움) / 미확보=빈 방패. 단색, 모양으로 구분, 하단 범례. (반원·세모는 폐기 — 세모는 '경고'로 오인)
- **원문 하이라이트**(검토 상세): 광고 상세페이지를 **실제처럼 재현**(`.adpage`, 테마 무관 흰 종이), 의심 문구는 **노란 형광펜(`#ffe98a`) + 빨간 번호 뱃지**. 스크롤 점프+flash.
- **차트:** 단일 색상 명도 램프(색상 아니라 밝기로 구분 = CVD 안전). 값 직접 라벨. 형태 섞기(파이프라인/스택/순위/스탯).

## 4. 색각이상 — 검증 절차 (중요, 눈으로 판단 금지)

dataviz 스킬의 검증기로 팔레트를 **반드시 통과**시킨 뒤 씀:
```bash
# 스킬 경로의 validate_palette.js 를 .mjs로 복사 후 (package.json에 {"type":"module"})
node validate_palette.js "#12509e,#5b7bb0,#a4b6d0" --mode light --ordinal
```
- 이미 잡은 결함(참고): 램프 대기색 `#bccadd`(1.62:1 FAIL) → `#a4b6d0`(2.01 PASS). 다크 `#31435c` → `#3c5372`.
- **위해 앰버↔빨강은 적록색약 ΔE 2.1로 구분 불가** → 앰버 제거, "중"을 회색으로. 색은 "고"에만.
- 최종 램프: 라이트 `#12509e,#5b7bb0,#a4b6d0` / 다크 `#5b9be8,#4a7099,#3c5372` (검증 통과).

## 5. 화면별 특기 사항

**검토 큐** — 액션 컬럼 없음(진행 컬럼과 중복이라 삭제). 진입은 우측 패널 "상세 검토" 버튼 + 상품명 옆 ↗ 원본링크 아이콘. 요약 통계는 접이식 토글(기본 접힘, 큐 우선). 페이지당 20/50/100.

**검토 상세** — 기획안 §6·§12 준수: ①상단 원본+하단 판단(상하 분할) ②법령 근거와 **참고 사례 영역 분리**("법적 근거 아님" 명시) ③법령에 시행일·출처 + "관련 근거 부족" 상태 ④제품유형 수정→**재분석 버튼**(발표 유일 라이브 요소) ⑤판정 4버튼(승인/기각/보류/**협의**). 판정 독+단축키 바 한 줄 통합.

**대시보드** — KPI = 관리자의 4질문(적체 순증/기한 초과/이행률/미탐률), 각 칸 스파크라인 내장. 업무흐름=파이프라인. 담당자 부하 크게(배정 결정). **AI 모델 카드가 상태로 커짐**: ①축적중 69px 한 줄 → ②학습권장 188px → ③배포대기 366px(최상단, 챔피언-챌린저+배포기준). 목업 상단 버튼으로 3상태 전환 가능.

## 6. 도메인 매핑 (문서 근거)
- **4탭 "공이 누구 손에":** 신고/탐색/진행 중/추적 (+전체).
- **2축:** 판정 확실성(근거 명확/추가 판단 필요) × 긴급도(회신 기한→위해 등급→FIFO).
- **위해 등급:** 고/중/저 (한글). **최종 판단은 사람**(Human-in-the-Loop).
- **모델:** 챔피언-챌린저, 미탐율 1급 지표, 관리자 셀프-재학습(F18)·미탐 재탐지(F19).
